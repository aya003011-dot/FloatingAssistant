دستیار شناور نسخه 1.1 — راهنما

این ZIP سورس پروژه است، نه APK آماده.

قابلیت‌ها:
- پنجره شناور با کادر تایپ فارسی
- دکمه‌های + و − برای تغییر اندازه و کشیدن عنوان برای جابه‌جایی
- بازکردن یوتیوب و جستجوی عبارت از داخل URL، با اصلاح چند غلط رایج مانند aneim -> anime
- بازکردن تیک‌تاک، جستجوی گوگل، تنظیمات VPN، وای‌فای و بلوتوث
- سرویس دسترس‌پذیری اختیاری برای «روی [متن] کلیک کن»، «تایپ کن [متن]» و برگشت؛ کاربر باید آن را دستی در تنظیمات فعال کند.

محدودیت‌ها:
- این برنامه هنوز به مدل ChatGPT یا مدل زبانی آنلاین متصل نیست؛ اصلاح غلط‌ها و درک فرمان‌ها محلی و محدود است.
- Android برنامهٔ معمولی را از خاموش/روشن‌کردن مستقیم VPN، Wi-Fi و بعضی تنظیمات محافظت می‌کند. برای VPN باید خود کاربر در تنظیمات آن را تغییر دهد.
- دسترس‌پذیری دسترسی حساسی است؛ فقط اگر به آن نیاز داری فعالش کن.

ساخت در GitHub Actions:
1) فایل‌ها را در پروژهٔ GitHub جایگزین و push کن.
2) وارد Actions شو، اجرای سبز را باز کن و artifact با نام FloatingAssistant-debug را دانلود کن.
3) ZIP artifact را استخراج کن و app-debug.apk را نصب کن.

نسخهٔ جدید باید با همان package applicationId نصب/آپدیت شود. اگر قبلی را با کلید امضای متفاوت ساخته‌ای، اندروید ممکن است آپدیت را قبول نکند؛ در این صورت قبلی را حذف کن (تنظیماتش پاک می‌شود) و APK تازه را نصب کن.
