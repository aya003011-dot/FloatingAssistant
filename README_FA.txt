دستیار شناور — نسخهٔ پیشرفته

قابلیت‌هایی که در این نسخه اضافه شده:
- ورودی صوتی فارسی از طریق موتور تشخیص گفتار موجود روی گوشی؛ ممکن است سرویس گفتار برای تشخیص صدا به اینترنت نیاز داشته باشد.
- بازکردن برنامه‌های نصب‌شده با نام آنها، از جمله تلاش برای شناسایی تلگرام، تیک‌تاک، گالری و VPN Star.
- دکمهٔ ◉ پنجره را مخفی می‌کند؛ دکمهٔ کوچک ✦ روی صفحه می‌ماند و با لمس آن پنجره برمی‌گردد. خود دکمهٔ ✦ را هم می‌شود جابه‌جا کرد.
- فرمان‌های محلی برای Wi‑Fi، بلوتوث، جستجو، برگشت و نوشتن/کلیک روی متن قابل‌مشاهده (با مجوز دسترس‌پذیری).
- اتصال هوش مصنوعی اختیاری از طریق سرور واسط. سرور در پوشهٔ server است.

نکتهٔ بسیار مهم دربارهٔ ChatGPT / هوش مصنوعی:
این برنامه مستقیماً به همین گفت‌وگوی ChatGPT وصل نیست. برای پاسخ‌های هوشمند آنلاین باید API جداگانه و سرور خودت را راه‌اندازی کنی. استفاده از API ممکن است هزینه داشته باشد. کلید OpenAI را هرگز داخل APK، کد اندروید یا مخزن GitHub قرار نده. کلید فقط باید در متغیرهای خصوصی سرور ذخیره شود.

راه‌اندازی سرور (نیاز به میزبانی با Node.js 20+ و HTTPS دارد):
1. پوشهٔ server را روی یک VPS/میزبان Node.js قرار بده.
2. در تنظیمات خصوصی آن میزبان، OPENAI_API_KEY را با کلید API خودت مقداردهی کن.
3. برای ASSISTANT_ACCESS_TOKEN یک رشتهٔ تصادفی قوی بساز؛ نمونهٔ ساخت روی لینوکس: openssl rand -hex 32. این توکن را به هیچ‌کس نده.
4. OPENAI_MODEL را در صورت نیاز روی مدلی قرار بده که در حساب API خودت در دسترس است. مقدار پیش‌فرض gpt-6-astra است و ممکن است لازم باشد آن را با نام مدل قابل‌دسترسی در حسابت جایگزین کنی.
5. دستور شروع سرور: npm install && npm start
6. سرور باید از طریق HTTPS در دسترس باشد. مسیر بررسی سلامت /health و مسیر فرمان /command است.
7. داخل برنامه روی «تنظیم اتصال هوش مصنوعی» بزن و URL پایهٔ HTTPS (بدون /command) و همان ASSISTANT_ACCESS_TOKEN را وارد و ذخیره کن. کلید OPENAI_API_KEY را اینجا وارد نکن.

محدودیت‌های مهم:
- اگر سرور راه‌اندازی نشود، فرمان‌های سادهٔ محلی باز هم کار می‌کنند؛ فهم طبیعی گسترده بدون اتصال آنلاین محدود است.
- نام برنامه‌ها تا جایی قابل‌شناسایی است که در فهرست برنامه‌های قابل‌اجرا ظاهر شوند. بعضی سازندگان گوشی یا برنامه‌ها ممکن است نمایش برنامه‌ها را محدود کنند.
- اندروید اجازه نمی‌دهد همهٔ تنظیمات امنیتی را بی‌قیدوشرط تغییر دهیم. VPN Star باز می‌شود، اما ممکن است لازم باشد خودت دکمهٔ اتصال را بزنی و اجازهٔ سیستمی VPN را تأیید کنی.
- درخواست ارسال پیام در تلگرام برنامه را باز می‌کند؛ برای جلوگیری از ارسال به مخاطب اشتباه، انتخاب مخاطب، بررسی متن و فشردن Send را خودت انجام بده.
- سرویس دسترس‌پذیری فقط در صورتی روی متن قابل‌مشاهده کلیک یا در کادر فعال تایپ می‌کند که خودت آن را در تنظیمات اندروید فعال کرده باشی. قبل از واردکردن پیام‌ها و اطلاعات خصوصی، متن و مخاطب را بررسی کن.
- هیچ برنامه‌ای نمی‌تواند «همه‌چیز را بداند» یا هر کاری را بدون محدودیت انجام دهد؛ این نسخه برای چند فرمان عملی طراحی شده و ممکن است بعضی نسخه‌های اندروید/برنامه‌ها رفتار متفاوتی داشته باشند.

ساخت APK:
این پروژه شامل workflow گیت‌هاب است. پس از جایگزینی فایل‌ها و push کردن تغییرات به شاخهٔ main، به بخش Actions مخزن برو. وقتی Build سبز شد، artifact با نام FloatingAssistant-debug را دانلود کن، از حالت ZIP خارج کن و APK داخل آن را روی گوشی نصب کن.
