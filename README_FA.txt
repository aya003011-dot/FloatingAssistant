دستیار شناور — نسخهٔ 1.4 آفلاین‌محور

این بسته برای ساخت APK با GitHub Actions آماده شده است. این نسخه به Render، VPS، کلید OpenAI یا اشتراک API نیاز ندارد.

قابلیت‌ها
- فرمان‌های محلی فارسی: بازکردن بعضی برنامه‌ها، صدا، صفحهٔ اصلی، برگشت، وای‌فای/بلوتوث، مخفی‌کردن پنجره و اسکرین‌شات با مجوز دسترس‌پذیری.
- پنجرهٔ شناور با حباب ✦ برای برگرداندن پنجره.
- چند پاسخ پایهٔ فارسی و محاسبات ساده به‌صورت محلی؛ متن این فرمان‌ها به سرور ارسال نمی‌شود.
- جستجوی گوگل/یوتیوب/تیک‌تاک در مرورگر، با اینترنت.
- فرمان صوتی فارسی؛ برنامه به سرویس گفتار نصب‌شده می‌گوید در صورت پشتیبانی از مدل روی دستگاه استفاده کند.

محدودیت مهم و صادقانه
این نسخه یک موتور فرمان و پاسخ آفلاین سبک است، نه یک مدل زبانی بزرگ مثل ChatGPT. برای مکالمهٔ مولد باکیفیت کاملاً آفلاین، باید یک مدل جداگانه روی گوشی دانلود و اجرا شود؛ این کار فضای زیادی می‌خواهد و روی گوشی‌های کم‌حافظه ممکن است بسیار کند باشد. جستجوی گوگل نیز نتایج را در مرورگر باز می‌کند و خودش صفحه‌ها را نمی‌خواند یا خلاصه نمی‌کند.

صدا به‌صورت آفلاین
EXTRA_PREFER_OFFLINE فقط یک درخواست به سرویس گفتار اندروید است و تضمین نمی‌کند که مدل فارسی آفلاین نصب باشد. اگر صدا بدون اینترنت کار نکرد، در تنظیمات Google/Voice یا تنظیمات گفتار گوشی امکان دانلود زبان فارسی را بررسی کن؛ در غیر این صورت دستورها را تایپ کن.

نصب پس از ساخت APK
1. مخزن GitHub را با فایل‌های این بسته به‌روزرسانی کن.
2. در GitHub به Actions برو و workflow با نام Build Floating Assistant APK را اجرا کن یا منتظر اجرای خودکار بعد از push بمان.
3. اجرای سبز را باز کن و از بخش Artifacts فایل FloatingAssistant-OfflineFirst-debug را دانلود کن.
4. ZIP را استخراج کن و APK داخلش را روی گوشی نصب کن. اگر Android از نصب از منبع ناشناس هشدار داد، فقط در صورتی اجازه بده که فایل را از مخزن خودت دانلود کرده باشی.
5. برنامه را باز کن و اجازهٔ پنجرهٔ شناور و میکروفون بده. دسترس‌پذیری اختیاری است؛ فقط اگر فرمان‌های کنترل صفحه/اسکرین‌شات را می‌خواهی، آن را از تنظیمات اندروید فعال کن.

نمونهٔ فرمان‌ها
- «برو تلگرام»
- «صدا رو زیاد کن»
- «صدا رو کم کن»
- «برگرد» یا «خانه»
- «وای‌فای» یا «بلوتوث»
- «مخفی کن»
- «حاصل ۲ + ۳»
- «ساعت چنده»
- «سرچ کن آخرین اخبار»
- «دربارهٔ [موضوع]» یا یک سؤال کامل؛ اگر اینترنت وصل باشد جستجوی گوگل باز می‌شود.

حریم خصوصی و امنیت
- در این نسخه کد سرور و API key وجود ندارد و API key نباید داخل پروژه یا APK گذاشته شود.
- چون کلید OpenAI قبلی در گفت‌وگو نمایش داده شده بود، آن کلید را لغو کن و دیگر استفاده نکن. این نسخه به آن کلید احتیاجی ندارد.
- برای ارسال پیام در برنامه‌های پیام‌رسان، مخاطب و متن را خودت بررسی کن و خودت دکمهٔ ارسال را بزن.
- مجوز دسترس‌پذیری قدرتمند است؛ فقط اگر به کنترل صفحه نیاز داری آن را فعال کن.

ساختار اصلی
- app/src/main/java/com/example/floatingassistant/OfflineBrain.java : پاسخ‌ها و محاسبه‌های محلی
- FloatingService.java : پنجرهٔ شناور، فرمان‌های گوشی و جستجو
- VoiceCommandActivity.java : تشخیص صدای فارسی از سرویس گفتار Android
- .github/workflows/build.yml : ساخت APK در GitHub Actions
