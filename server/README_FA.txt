راهنمای سرور دستیار شناور

این سرور اختیاری است و فقط برای فهم طبیعی فرمان‌ها و پاسخ‌های هوش مصنوعی استفاده می‌شود.
نیازمندی‌ها: Node.js 20 یا جدیدتر، دسترسی HTTPS، یک کلید OpenAI API با امکان استفاده از مدلی که تنظیم می‌کنی.

روی سرور، متغیرهای خصوصی زیر را تنظیم کن:
- OPENAI_API_KEY: کلید API خصوصی. هرگز آن را در APK، برنامهٔ اندروید یا GitHub قرار نده.
- ASSISTANT_ACCESS_TOKEN: یک توکن تصادفی طولانی که خودت می‌سازی. همان توکن را در تنظیمات برنامه وارد می‌کنی.
- OPENAI_MODEL: شناسهٔ مدلی که در حساب API خودت دسترس داری (پیش‌فرض: gpt-6-astra).
- PORT: اختیاری؛ در غیر این صورت 8080.

سپس از داخل این پوشه اجرا کن: npm install && npm start

GET /health برای بررسی روشن بودن سرور است. POST /command با هدر X-Assistant-Token برای فرمان‌ها استفاده می‌شود. سرور برای هر IP محدودیت سادهٔ درخواست دارد. سرور را فقط پشت میزبانی دارای HTTPS در اینترنت قرار بده؛ پورت خام را بدون TLS عمومی نکن.

برنامه نام فرمان و فهرست نام برنامه‌های قابل اجرا را به سروری که وارد کرده‌ای می‌فرستد. مخاطبان، چت‌ها یا متن صفحه به‌طور خودکار فرستاده نمی‌شوند مگر کاربر فرمان جداگانه‌ای برای تایپ/کلیک بدهد. پیام‌رسانی و مجوز اتصال VPN نیاز به بازبینی و تأیید خود کاربر دارد.
